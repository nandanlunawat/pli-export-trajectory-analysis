# 02_policy_sources/

`source_log.csv` is the audit trail: every external claim used anywhere in the
project, with a verbatim quote, an evidence tier, a source URL and a retrieval date.

Evidence tiers:
  V        verified from a primary/authoritative source
  C        conflicting official sources; both recorded
  OPEN     requires an empirical check before it can be relied on
  NOT VERIFIED   could not be confirmed; must not be asserted

Scheme gazettes and notifications should be archived here as PDFs so the project
does not depend on government URLs remaining live. Several already 404 after site
migrations (DoT's telecom notification, DPIIT's white-goods copies).
